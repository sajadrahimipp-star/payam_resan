# نووا | پیام‌رسان آنلاین فارسی (نسخه ۲ — شبیه تلگرام)

پیام‌رسان وب راست‌چین با امکانات پیشرفته: چت شخصی، مخاطبین، گروه، کانال، وضعیت آنلاین و پیام‌رسانی لحظه‌ای با Socket.IO.

## امکانات جدید (نسخه ۲)
- **چت شخصی** یک‌به‌یک با هر کاربر
- **مخاطبین**: اضافه کردن و مدیریت لیست مخاطب
- **گروه**: ساخت گروه و دعوت اعضا از مخاطبین
- **کانال**: ساخت کانال (فقط ادمین/سازنده می‌تواند پست بگذارد)
- لیست گفتگوها با آخرین پیام و تعداد پیام‌های خوانده‌نشده
- جستجوی کاربران برای شروع چت یا افزودن مخاطب
- نمایش وضعیت آنلاین/آفلاین
- نشانگر «در حال نوشتن…»
- حالت روشن و تاریک (پیش‌فرض تاریک شبیه تلگرام)
- رابط واکنش‌گرا برای موبایل

## پیش‌نیاز
Node.js نسخه ۲۰ یا جدیدتر (ترجیحاً ۲۲ LTS) و npm.

## اجرای محلی
1. فایل ZIP را از حالت فشرده خارج کن.
2. در پوشه پروژه ترمینال باز کن.
3. وابستگی‌ها را نصب کن:

   ```bash
   npm install
   ```

4. کلید نشست را تنظیم کن و اجرا کن:

   ```bash
   SESSION_SECRET="یک-رشته-تصادفی-طولانی" npm start
   ```

   در ویندوز PowerShell:

   ```powershell
   $env:SESSION_SECRET="یک-رشته-تصادفی-طولانی"
   npm start
   ```

5. مرورگر را باز کن و به `http://localhost:3000` برو.
6. برای آزمایش کامل:
   - دو یا سه حساب کاربری بساز (مرورگر عادی + ناشناس).
   - از دکمه ＋ چت شخصی، گروه یا کانال بساز.
   - کاربران را جستجو کن و به مخاطبین اضافه کن.

## ساختار پروژه
- `server.js` — سرور Express، نشست‌ها، API و Socket.IO
- `public/index.html` — ساختار صفحه
- `public/styles.css` — ظاهر شبیه تلگرام
- `public/app.js` — منطق رابط کاربری
- `nova.sqlite` — هنگام اجرا ساخته می‌شود

## نکات
- پیام‌ها در این نسخه رمزنگاری سرتاسری (E2EE) ندارند.
- برای استفاده عمومی، `SESSION_SECRET` قوی، HTTPS و پشتیبان‌گیری از دیتابیس ضروری است.
- SQLite برای تک‌نمونه مناسب است؛ برای مقیاس بالاتر به پایگاه داده مشترک و Redis نیاز است.
